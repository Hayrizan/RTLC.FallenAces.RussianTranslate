# Шрифты

AssetBundle содержит четыре шрифта с кириллицей. Плагин создаёт динамические SDF-атласы и сопоставляет их с семействами, используемыми игрой.

| Семейство игры | Файл | Примечание |
|---|---|---|
| Action Man | `Troubleside.ttf` | TroubleSide, Evgeny Koroletov / Lugansk Contemporary Diaspora; SIL Open Font License 1.1 |
| Broadway CG | `Broadway Cyrillic Extended.ttf` | Broadway Cyrillic с добавленными Ё/ё; распространяется с разрешения правообладателя |
| Brush Script Std | `brushscriptstd.ttf` | Adobe Brush Script Std; распространяется с разрешения правообладателя |
| Josefin Sans | `JosefinSansExt-Regular.ttf` | Расширение Josefin Sans с кириллицей; SIL Open Font License 1.1 |

Сопоставления хранятся в `Fonts/fonts.json`. Изменение шрифтов или путей требует пересборки AssetBundle. Шрифты с лицензией OFL поставляются по условиям этой лицензии; у двух остальных файлов право на распространение предоставлено отдельно.
