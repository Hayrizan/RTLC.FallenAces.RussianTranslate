# Замена текстур

PNG помещаются в `BepInEx/plugins/RTLC.FallenAces.RussianTranslate/Textures/`. Допускаются подпапки, но имена файлов должны быть уникальными. Файл называется:

```text
ИмяИсходнойТекстуры__ШиринаxВысота.png
```

Пример: `MenuButtonPressed__313x86.png`. Недопустимые для Windows символы в исходном имени заменяются на `_`. Размер PNG обязан точно совпадать с оригиналом. Сохраняйте альфа-канал. Подмена изменяет исходный объект Texture2D в памяти, поэтому существующие спрайты, UV, прямоугольники и точки привязки продолжают использовать его; фильтрация и адресация сохраняются. Атласы шрифтов защищены от такой подмены.

## Как получить исходники с правильными именами

1. Запустите игру с плагином и завершите её.
2. В `BepInEx/config/rtlc.fallenaces.russiantranslate.cfg` включите:

```ini
[Textures]
ExportLoadedTextures = true
```

3. Запустите игру и откройте нужное меню/уровень. Загруженные текстуры постепенно экспортируются в `TextureDump` рядом с DLL. Экспорт читает GPU-текстуры, даже если оригинал недоступен для чтения с CPU. Может потребоваться много места и времени.
4. Выключите экспорт после получения нужных изображений. Отредактированные PNG скопируйте из `TextureDump` в `Textures`, сохранив имена и размеры. Перезапустите игру.

Подмены загружаются при старте. Ресурсы проверяются порциями и после загрузки новых сцен; текстура может замениться через несколько кадров. Не включайте экспорт для обычного прохождения.

Текстуры с одинаковыми именами **и** размерами получают одну и ту же подмену. Если игра использует такие дубликаты с разным содержимым, потребуется отдельное адресное правило; текущий формат не различает их. Запечённые SpriteAtlas необходимо редактировать целиком с сохранением расположения элементов. Исходные картинки и ваши переведённые изображения в этот архив не включены.
