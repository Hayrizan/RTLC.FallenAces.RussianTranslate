# RTLC.FallenAces.RussianTranslate

Русский перевод Fallen Aces для Windows x64. Плагин рассчитан на версию игры 0.9.4 (Unity 6, Mono); текущая версия перевода — 0.1.0.

Переведены интерфейс, настройки, подсказки, сообщения, названия предметов и оружия, записки, журнал, обучение и субтитры. Текстовые ключи переводятся без изменения файлов игры.

## Скачать и установить

Скачайте [последний архив русификатора](https://github.com/Hayrizan/RTLC.FallenAces.RussianTranslate/releases/latest/download/FallenAces-RussianTranslate-0.1.0.zip) и распакуйте его в папку, где находится `Fallen Aces.exe`, сохраняя структуру архива. В архив уже включён официальный BepInEx 5.4.23.5 x64 и плагин. Файлы перевода находятся в `BepInEx/plugins/RTLC.FallenAces.RussianTranslate/`.

Запустите игру. Русский перевод включён по умолчанию. Архив не содержит DLL и текстуры самой игры; установщик ничего не меняет автоматически.

## Сборка из исходников

Нужны .NET SDK 10, Python 3 с UnityPy 1.25.0, Unity Editor 2022.3.62f2 с Windows Build Support и установленная Steam-версия игры. Сборка использует DLL игры только для ссылок компиляции и для проверки, что её текстовые ресурсы соответствуют проверенной версии.

```powershell
python -m pip install -r requirements.txt
$env:FALLEN_ACES_DIR = Read-Host 'Путь к папке Fallen Aces'
$env:UNITY_EDITOR = Read-Host 'Путь к Unity.exe версии 2022.3.62f2'
.\build.ps1
```

Также можно задать переменные `FALLEN_ACES_DIR` и `UNITY_EDITOR`. Скрипт загружает официальный архив BepInEx 5.4.23.5, сверяет его SHA-256, запускает проверки переводов и собирает AssetBundle. Готовый ZIP появится в `dist/`; игровые файлы при этом не изменяются. Лицензии и уведомления сторонних компонентов включаются в архив в `ThirdPartyLicenses/`.
